# Enterprise Network Infrastructure – Cisco Packet Tracer

## Project Overview

A hands-on enterprise network project designed and implemented using Cisco Packet Tracer.

The project simulates a Main Office and a Branch Office connected through routers, with VLAN segmentation, inter-VLAN routing, network services, and basic security.

## Network Features

- VLAN segmentation
- Inter-VLAN routing
- Layer 3 Core Switching
- Static routing
- Main Office and Branch connectivity
- DHCP
- DNS
- HTTP Web Server
- Network Printer
- Basic device security
- Network connectivity testing

## Network Services

The centralized server provides:

- DHCP
- DNS
- HTTP

The website is accessible through:

`hajar.com`

## Testing

Connectivity was verified using:

- Ping tests between network segments
- Main Office to Branch connectivity
- Branch to centralized server connectivity
- DNS name resolution
- Web access through `hajar.com`

## Tools

- Cisco Packet Tracer
- Cisco IOS CLI
